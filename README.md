# DAF Speech Practice

吃音者の発話練習をローカル PC 上で補助する、Windows 向けの軽量 Electron アプリです。医療行為、診断、治療ではなく、セルフトレーニングの補助ツールとして設計しています。

## 主な機能

- マイク入力の取得
- 入力デバイスと出力デバイスの選択
- Delayed Auditory Feedback（DAF）として 50〜250ms の遅延音声をイヤホンへ返す
- DAF 音量調整
- 40〜180 BPM のメトロノーム、音色選択、おすすめ BPM プリセット
- 録音、停止、再生
- カテゴリ別の練習テキスト表示、ランダム表示、次のテキスト、編集
- 日本語 / 英語 UI 切り替え
- localStorage による設定保存

# DAF Speech Practice

吃音者の発話練習をローカル PC 上で補助する、Windows 向けの軽量 Electron アプリです。医療行為、診断、治療ではなく、セルフトレーニングの補助ツールとして設計しています。

## 主な機能

- マイク入力と音声出力デバイスの選択
- Delayed Auditory Feedback（DAF）として 50〜250ms の遅延音声をイヤホンへ返す
- 通常の常時 DAF モード
- フットペダルや任意キーを押している間だけ DAF を出力する Hold-to-DAF モード
- デフォルトのトリガーキーは `F13`
- `F13` / `F14` / `Space` のプリセットと、任意キーの記録
- 50〜150ms のフェードイン / フェードアウト
- 40〜180 BPM のメトロノーム、音色選択、おすすめ BPM プリセット
- 録音、停止、再生
- カテゴリ別の練習テキスト表示、ランダム表示、次のテキスト、編集
- 日本語 / 英語 UI 切り替え
- localStorage による設定保存

## Hold-to-DAF の使い方

1. イヤホンまたはヘッドホンを接続します。
2. `音声設定` で入力デバイスと出力デバイスを選びます。
3. `DAF` カードで `マイク開始` を押します。
4. `Hold-to-DAF` を有効にします。
5. USB フットペダル側の割り当てキーを `F13` に設定します。
6. フットペダルを踏んでいる間だけ `DAF ON` になり、離すとフェードアウトして `DAF OFF` になります。

`Space` や `A`〜`Z` も設定できますが、ゲームや文字入力と競合する可能性があります。フットペダルには `F13`〜`F24` を推奨します。`uiohook-napi` によるグローバル keydown / keyup 監視を使っているため、アプリが背面にある状態でもフットペダルの押下/離上で Hold-to-DAF が切り替わります。

## 開発

Node.js 20 以上と npm をインストールしてから実行してください。

```powershell
npm install
npm run dev
```

## Windows ビルド

```powershell
npm run dist:win
```

ビルド成果物は `release` に出力されます。展開済みアプリは通常 `release/win-unpacked/DAF Speech Practice.exe` から起動できます。

## 音声の注意

DAF は自分の声を遅らせて再生するため、イヤホンまたはヘッドホンの使用を想定しています。スピーカー出力ではハウリングが起きる場合があります。初回は音量を低めにして確認してください。

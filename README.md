# DAF Speech Practice

Windows PC向けの、吃音・発話練習を補助するElectronデスクトップアプリです。医療行為、診断、治療ではなく、個人検証とセルフトレーニングのための軽量ツールとして設計しています。

## 主な機能

- マイク入力と出力デバイスの選択
- DAF: 自分の声を50〜250ms遅らせてイヤホンへ返す
- FAF: 自分の声の高さを半音単位で変えて返す
- `OFF` / `DAF` / `FAF` / `DAF+FAF` の切り替え
- Hold-to-use: フットペダルやキーを押している間だけDAF/FAFを有効化
- デフォルトのトリガーキーは `F13`
- Speaking Pace Monitor: 音声認識を使わず、RMSから発話ペースを可視化
- 録音、メトロノーム、練習テキスト、日本語/英語UI
- 使用ログとセルフ評価のJSON / CSV出力

## 使い方

1. イヤホンまたはヘッドホンを接続します。
2. `音声設定` で入力デバイスと出力デバイスを選びます。
3. `DAF` カードで `マイク開始` を押します。
4. `使用モード` で `DAF` / `FAF` / `DAF+FAF` を選びます。
5. 必要に応じて遅延、FAFピッチ、音量、片耳/両耳出力、プリセットを調整します。
6. `Hold-to-use` を有効にすると、トリガーキーを押している間だけ効果が出ます。

## フットペダル推奨設定

USBフットペダルはHIDキーボードとして扱います。フットペダル側の割り当てキーは `F13` を推奨します。

`F13` に設定したペダルを踏んでいる間だけ `DAF` / `FAF` / `DAF+FAF` が有効になり、離すとフェードアウトして `OFF` になります。`Space` や `A`〜`Z` も設定できますが、ゲームや文字入力と競合する可能性があります。フットペダルには `F13`〜`F24` を推奨します。

## Speaking Pace Monitor

Speaking Pace Monitorは、音声認識を使わず、マイク入力の音量変化から現在の発話ペースを推定します。音声データそのものは保存しません。

- 直近5秒間の発話密度を計算
- 300ms以上の無音をpauseとしてカウント
- 音量ピークの平均間隔を計算
- `Calm` / `Good Pace` / `Fast` を穏やかな表示で通知
- 感度スライダーで検出しやすさを調整
- Fast判定の回数と時間を使用ログ、セルフ評価、CSV/JSON出力に含める

Fast表示は警告ではなく、早口に気づくための目安です。表示文言も `Take a breath` など、焦らせない表現にしています。

## 検証ログとセルフ評価

アプリは個人情報を保存しません。保存する内容は以下です。

- 使用日時
- 使用モード
- DAF遅延ms
- FAFピッチ量
- 使用時間
- Hold使用か常時使用か
- 片耳/両耳
- プリセット名
- Speaking Pace MonitorのFast判定回数/時間
- セルフ評価 1〜5 と自由記述

`検証ログ` パネルからJSONまたはCSVで出力できます。検証協力者から送ってもらう場合はCSVが扱いやすい形式です。

## 開発

Node.js 20以上とnpmをインストールしてから実行してください。

```powershell
npm install
npm run dev
```

## Windowsビルド

```powershell
npm run dist:win
```

ビルド成果物は `release` に出力されます。

- インストーラー: `release/DAF Speech Practice Setup 0.1.0.exe`
- 展開済みアプリ: `release/win-unpacked/DAF Speech Practice.exe`

## 音量と安全上の注意

DAF/FAFは自分の声を加工して再生するため、イヤホンまたはヘッドホンの使用を想定しています。スピーカー出力ではハウリングが起きる場合があります。最初は音量を低めにして確認してください。

このアプリは医療行為、診断、治療ではありません。吃音や早口症などの症状や不安がある場合は、医師、言語聴覚士、その他の専門家に相談してください。
